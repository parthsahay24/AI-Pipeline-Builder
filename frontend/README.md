# Frontend (React Application)

This directory contains the highly interactive ReactFlow user interface for the VectorShift Technical Assessment. 

It features:
- ReactFlow interactive node dragging and connecting
- CSS Houdini revolving `@property` animations and glassmorphic UI cards
- Full Dark Mode / Light Mode support contexts
- GSAP and Framer Motion physical animation springs
